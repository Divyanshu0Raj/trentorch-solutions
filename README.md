## 🚀 About This Repository

Welcome to my **TrenTorch Solutions** repository!

This is where I document my daily Python programming practice through exercises from [TrenTorch](https://trentorch.com/).

I use the TrenTorch interactive coding environment to understand concepts, solve programming challenges, experiment with different approaches, and strengthen my problem-solving skills.

Instead of letting completed exercises disappear, I maintain this repository as a structured record of my learning journey.

**The goal is not just to write code, but to understand how and why it works.**

## 🧠 Current Practice Focus

### Python Strings — Immutability

One of my current exercises explores how Python handles immutable strings.

**Topics covered:**

- Understanding string immutability.
- Modifying strings without changing the original object.
- String concatenation using `+` and `+=`.
- String repetition using `*`.
- Understanding the copying cost of repeated concatenation.

**Practice:** [Open Exercise on TrenTorch](https://trentorch.com/ide/python-strings-immutability)

**My implementation:** [View Solution](./python-strings-immutability/solution.py)

## 💻 Run Solutions Locally

Clone the repository:

```bash

```

Navigate into the project:

```bash
cd trentorch-solutions
```

Run an individual Python solution:

```bash

```

**Note:** Some exercise files contain function definitions intended for an interactive exercise runner. They may not produce output when executed directly.
